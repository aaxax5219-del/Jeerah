# Jeerah - جيرة

## تشغيل محلي
1. ثبتي Node.js.
2. نفذي `npm install`.
3. شغلي `npm start`.
4. افتحي `http://localhost:3000`.

## النشر على Render
- Build Command: `npm install`
- Start Command: `npm start`
- Root Directory: اتركيه فارغاً إذا كان `server.js` و`package.json` في جذر المستودع.
- يفضّل إضافة متغير بيئة `SESSION_SECRET` بقيمة طويلة وعشوائية ثابتة حتى تبقى جلسات الدخول صالحة بعد إعادة تشغيل الخدمة.
- أضيفي قرصاً دائماً (Persistent Disk) إذا أردتِ الاحتفاظ بقاعدة SQLite؛ اربطيه بمسار مناسب ثم عدّلي مسار قاعدة البيانات في `server.js` ليتوافق معه.

## صلاحيات المنشورات
- يجب إنشاء حساب أو تسجيل الدخول قبل إضافة منشور.
- يُربط المنشور بمعرّف الحساب في قاعدة البيانات.
- يظهر زر الحذف لصاحبة المنشور فقط.
- الخادم يتحقق من ملكية المنشور قبل الحذف، لذلك لا يكفي إخفاء الزر في الواجهة لمنع حذف منشورات الآخرين.
- المنشورات القديمة التي ليس لها `user_id` تبقى ظاهرة ولا يستطيع أي حساب حذفها.

كلمات المرور تُخزّن باستخدام scrypt مع salt، ولا تُحفظ كنص صريح.
